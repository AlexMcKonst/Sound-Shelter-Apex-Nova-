# Sound-Shelter-Apex-Nova-
Sound Shelter — это легковесный, настраиваемый веб-плеер для прослушивания интернет-радиостанций. Приложение работает локально в браузере, позволяет загружать собственные плейлисты в формате M3U, формировать списки избранного и глубоко кастомизировать внешний вид интерфейса.

Основные возможности
Работа с M3U-плейлистами: Загрузка файлов или целых папок с радиостанциями.

Управление избранным: Добавление станций в любимые, экспорт избранного в отдельный M3U-файл для использования в других плеерах.

Поиск и фильтрация: Быстрый поиск по названиям станций и URL-адресам потоков.

Кастомизация интерфейса: Поддержка нескольких цветовых схем (Тёмная, Светлая, Тёплая, Холодная, Пользовательская), настройка контрастности, толщины границ и установка собственных фоновых изображений (по ссылке или из файла).

Счетчик трафика: Отслеживание объема загруженных аудиоданных в текущей сессии.

Двуязычный интерфейс: Поддержка русского и английского языков (переключается на лету).

Интеграция с системой: Поддержка мультимедийных клавиш клавиатуры и системных виджетов управления плеером (Media Session API).

Инструкция по использованию
1. Первоначальная настройка и загрузка станций
Добавление папки с плейлистами: Нажмите на кнопку с иконкой папки (📁) в верхней части экрана и выберите директорию на вашем устройстве, в которой хранятся файлы .m3u. Плеер автоматически найдет все поддерживаемые файлы и добавит их в систему.

Переключение плейлистов: Используйте выпадающий список рядом с кнопкой папки, чтобы переключаться между загруженными списками станций.

Поиск: Введите название станции, жанр или часть ссылки в строку поиска. Плеер мгновенно отфильтрует текущий список или покажет результаты по всем загруженным файлам.

2. Воспроизведение и управление
Запуск станции: Нажмите на любую станцию в списке для начала воспроизведения. Название текущей станции отобразится на большой кнопке по центру.

Случайная станция: Нажмите на центральную широкую кнопку («Случайная станция» / «Random station»), чтобы плеер автоматически выбрал случайный поток из текущего списка.

Управление: Используйте кнопки Play и Pause под названием станции. Ползунок ниже позволяет регулировать громкость.

3. Работа с Избранным
Добавление/Удаление: Нажимайте на иконку звездочки (☆/★) рядом с названием станции, чтобы добавить её в Избранное или удалить оттуда.

Режим «Только избранное»: В меню настроек (⚙) можно активировать переключатель «Только избранное», чтобы скрыть все остальные станции и оставить на экране только ваш личный список.

Быстрое управление избранным: Под ползунком громкости расположены кнопки для быстрого добавления всех отфильтрованных станций в избранное, сохранения избранного в файл и его очистки.

4. Настройки приложения (Кнопка ⚙)
Доступ к меню настроек осуществляется через кнопку с шестеренкой в правом верхнем углу.

Язык интерфейса: Выбор между английским и русским языком (по умолчанию установлен английский).

Счетчик трафика: Включение опции «Загрузка» (Traffic) выведет в левый верхний угол экрана информацию о количестве мегабайт, скачанных за время прослушивания текущей станции.

Внешний вид: Выберите готовую цветовую тему или установите «Свою схему», чтобы самостоятельно выбрать основной оттенок с помощью цветового ползунка. Здесь же настраивается толщина обводки кнопок и общая контрастность.

Фоновое изображение:

Нажмите «🖼️ Изображение / ссылка».

Вы можете вставить прямую ссылку на картинку из буфера обмена или загрузить изображение с вашего устройства.

Переключатель «Фон включён» в самом верху настроек позволяет быстро скрывать или возвращать выбранный фон.

Экспорт и импорт настроек: Используйте кнопки 📤 и 📥 для сохранения всех параметров плеера (включая темы, язык и список избранных станций) в формате JSON, чтобы перенести их на другое устройство или в другой браузер.
