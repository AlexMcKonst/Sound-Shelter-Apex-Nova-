# Sound-Shelter-Apex-Nova-
Sound Shelter — это легковесный, настраиваемый веб-плеер для прослушивания интернет-радиостанций. Приложение работает локально в браузере, позволяет загружать собственные плейлисты в формате M3U, формировать списки избранного и глубоко кастомизировать внешний вид интерфейса.
